    What it gets right

    • \n, \r\n and a lone \r all end a line — including a \r\n torn in half by a chunk boundary.
    • Multi-line data: joins with newlines; exactly one space after the colon is stripped.
    • id: persists across events (and is ignored if it holds a NUL); retry: is honoured only when all ASCII digits.
    • : comment lines are reported, never dispatched — that is how keep-alives work.
    • A leading BOM is dropped, and multi-byte characters split across chunks still decode.
    • An event the stream ended without terminating is discarded, as the spec says.
