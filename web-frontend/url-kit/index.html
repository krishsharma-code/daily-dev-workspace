url-kit

Query strings and URLs, handled carefully: nested and repeated params, strict RFC 3986 encoding, tolerant decoding, and edits that leave the rest of the URL untouched.

Parsed params

parseQuery — repeated keys become arrays, a[] and a[b] become nested values, and every value is decoded.
