sort-kit

Click a column to sort. Shift+click adds a secondary key.

A staff register with a deliberately messy Salary column (two blanks, one value stored as text) and file-like Ticket references.

The Salary column is declared as a numeric key, so the text value and the blanks are handled by the comparator instead of by ad-hoc parseFloat calls in the click handler.
