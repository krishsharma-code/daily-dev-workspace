mask-kit

Input masks from a tiny pattern language: separators inserted for you, characters that do not fit dropped, and the caret kept where you are typing. Try a field, paste a formatted value into it, or edit in the middle of one.

Presets

Each field is a new MaskInput(input, { preset }). The readout underneath shows what field.value would submit — unmasked, separators stripped.

Custom pattern

0 is a digit, A a letter, * either; everything else is a literal. This field is wired straight to applyMask and caretFor.
