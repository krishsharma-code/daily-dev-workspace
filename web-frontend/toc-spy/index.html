toc-spy

A table of contents built from your headings, with the current section highlighted as you scroll.

Why a generated table of contents

Long documentation pages are hard to skim. Hand-written tables of contents drift out of sync the moment someone renames a heading, and they almost never tell the reader where they are. toc-spy reads the headings already in your markup, gives them stable anchor ids, and keeps the matching entry highlighted while the reader scrolls.

Quick start

Two lines and one element. The nav is filled in for you.

import { createTocSpy } from './toc-spy.js';

createTocSpy({
  content: document.querySelector('article'),
  nav: document.querySelector('#toc'),
  offset: 64, // height of a sticky header
});

What it generates

Nested <ul> markup, one anchor per heading, with data-toc-id attributes so styling and the active state need no extra bookkeeping.

Anchor ids

Heading text is slugified — diacritics folded, punctuation dropped, duplicates numbered. Headings that already carry an id keep it, so existing deep links still work.

Scrolling behaviour

The active entry is the last heading at or above the reading line, so a section stays highlighted while its content is on screen. Scroll to the very bottom and the final section wins, because the last section is usually too short to reach the top.

Sticky headers

Pass the header height as offset. It shifts the reading line and the scroll target, so clicked headings never land underneath a fixed header.

Resizing and re-rendering

Offsets are re-measured on resize, and a ResizeObserver watches the content element for images loading or sections collapsing. Call refresh() after you add headings yourself — try the button in the panel on the right.

Accessibility

The active link gets aria-current="location", links are real anchors with hashes, and focus outlines are visible. Smooth scrolling is skipped automatically by browsers when the reader prefers reduced motion, and you can turn it off with smooth: false.

API

The module exports four pure helpers plus the controller.

  • slugify(text) — heading text to a URL-safe id.
  • buildOutline(headings) — flat headings to a nested tree plus a flat list.
  • renderOutline(nodes) — outline to escaped, nested list markup.
  • findActiveIndex(offsets, scrollTop) — which section owns a scroll position.
  • createTocSpy(options) — the DOM controller: refresh, update, destroy.

Browser support

Any browser with ES modules and Element.closest. ResizeObserver is optional — without it the outline is measured on resize only.
